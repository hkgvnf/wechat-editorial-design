# 按内容目的组织公众号图文

用于活动预告、人物参会或发言报道、活动回顾、公司动态及节日寄语。先决定读者需要知道什么，再选择结构与画面；节日只是其中一种内容类型。

## 从需求确定文章任务

- 确定受众、文章目的、发布时点、语言、语气和用户需要的交付物。沿用已明确的简体中文或其他语言要求，不因素材语言不同而自行更改。
- 从用户请求和现有材料判断内容类型；一篇文章可以兼有参会报道与公司观点，不必强行归入单一模板。
- 区分已确认事实、可引用材料及待确认信息。先读用户提供的议程、邀请函、演讲稿、照片说明与原有文章；图片里的文字也需核对。
- 活动名称、日期、地点、主办方、参与者姓名与职务、参会身份、发言主题和活动状态应与可信材料一致。受邀、计划出席、实际出席、发言、签约是不同事实。
- 缺少影响标题或主叙事的关键信息时，集中询问最少的必要问题，同时继续素材整理和不依赖答案的版式工作。次要信息可以省略，不为填满模板反复追问。
- 草稿中的待确认标记只用于内部校对；正式导出前应确认、删除或改写相关内容，不能把占位信息当作事实交付。
- 以预定发布时点检查时态。尚未发生的活动不能写成回顾；日期临近或已经过去时，核对状态再使用“即将”“近日”“圆满举行”等表达。

## 按目的选择结构

以下是可调整的内容顺序，不要求固定段数、章节名或配图数量。材料较少时宁可做短篇，也不要补造背景或重复口号。

| 内容类型 | 读者最需要知道的内容 | 可采用的叙事顺序 |
| --- | --- | --- |
| 活动预告／邀请 | 活动是什么、面向谁、何时何地、怎样参与 | 核心看点 → 已确认安排 → 与读者的关系 → 必要的参与方式 |
| 人物参会／发言报道 | 谁以什么身份参与、做了什么、分享了什么 | 事件导语 → 参与或发言事实 → 有依据的观点 → 与公司或受众的联系 |
| 活动回顾 | 实际发生了什么、哪些环节值得回看 | 关键现场 → 重点环节 → 真实交流或成果 → 合适的后续信息 |
| 公司动态 | 什么发生了变化、涉及谁、有什么实际意义 | 核心变化 → 事实细节 → 对相关方的影响 → 已确认的下一步 |
| 节日寄语 | 对谁表达感谢、祝愿或关怀 | 真诚称呼 → 具体感谢或共鸣 → 祝福 → 简洁落款 |

### 活动预告与邀请

- 将日期、地点、议程、参与条件放在易读的位置。只有已获得确认的报名入口、截止时间、费用或名额才能写入。
- 提炼与目标读者有关的议题，避免仅堆砌主办方名单或通用宣传词。
- 主办方、协办方、赞助方和参会方的标志与称呼各有含义；严格按已确认的关系呈现，不因摆放在同一页而暗示背书。
- 用户只是公告活动时，不默认增加报名、销售或联系号召。

### 人物参会、发言与活动回顾

- 以已确认的参与身份和行为写导语，例如“代表团队参加交流”与“受邀作主题发言”不能互换。
- 发言内容优先依据演讲稿、记录或经确认的摘要。直接引语必须有原始依据；概述观点时不要包装成逐字发言。
- 区分讨论、意向、合作洽谈和正式达成的成果。合影或同场出现不能证明签约、合作、获奖或官方认可。
- 有素材时用“现场全景—人物行动—关键细节”的变化组织配图；不必按拍摄时间逐张罗列。
- 将参与的意义落到实际议题和分享内容，避免用空泛赞誉代替新闻事实。

### 公司动态

- 先说清发生的事情，再解释对客户、供应商、合作伙伴或员工的实际影响。
- 服务更新、团队活动、业务进展、办公变化等采用相应语气，不把每则动态都写成庆典或重大里程碑。
- 业绩、增长率、客户数量、交易、资质、奖项、职务、评价和引语都需有依据；不自行添加领先地位、成果承诺或未经证实的业务影响。
- 对尚在进行中的项目，按实际阶段写作；“已启动”“正在推进”和“已完成”应准确区分。
- 结尾可用事实落款或已确认的下一步。没有传播目的和有效入口时，不添加“立即咨询”等营销尾注。

## 让图片承担合适的作用

- 报道类内容优先使用用户提供或有权使用的真实照片、文件图示和活动视觉；记录来源、拍摄场景及已确认的人物说明，不根据外貌猜姓名或职务。
- 生成插画可表达抽象主题或作为装饰，不能冒充真实会场、参会人员、发言现场、奖项证书或签约证据。素材来源记录与读者可见署名按用户要求分别处理。
- 原始活动模板、主办方视觉和品牌 Logo 应保留规定的比例、组合和必要标注。引用资料的准确出处保留在素材清单中；成品可见署名按用户要求及素材许可中的必要标注处理，不额外添加创作尾注，也不暗示外部内容来自本公司。
- 真实照片的场景背景通常承担信息功能。不要为了融合统一抠成透明图，也不要用生成编辑增删人物、改写背景板、替换证件或制造现场事实。
- 可通过照片比例、对齐、留白、图注和边框统一版面；也可采用完整横幅或有意保留边界的照片。照片有边界不等于融合失败。
- 裁切先保护人物面部、证件、奖牌、演示内容、活动名称及关键标识；无法兼顾时换构图或完整展示，不靠遮罩盖掉必要事实。
- 多张照片选择不同信息层次，避免把同一合影的不同裁切当作不同环节。原图清晰度不足时调整显示大小或选替代素材，不虚构细节。
- 插画与照片可以共用边距、标题体系和少量品牌色，但不要求同一种背景处理。透明花枝等方法只在素材和主题适合时使用。
- 配色和装饰来自本次品牌、活动视觉与内容语气。商务活动、公司公告或人物报道不自动套用月亮、花灯、节日金色或祝福用语。

## 发布前按内容复核

- 对照原始材料检查标题、摘要、正文、封面、图片内文字和图注中的事实一致性；重点核对姓名、职务、机构关系、日期、数字和时态。
- 确认封面表达的是文章真正内容。人物未发言时不使用发言主题式标题，计划合作不写成达成成果。
- 确认每张真实照片与附近文案确实对应，保留必要的时间或场景说明，不用不同活动的照片制造同场印象。
- 结合 [设计与品牌](design-and-brand.md) 和 [配图连续性](artwork-continuity.md) 检查整篇节奏、手机可读性及视觉重复；事实审核不能替代视觉审核，视觉精美也不能代替事实依据。
- 交付用户需要的长图、封面、文案、切片或可编辑页，不因内容类型而强制增加整套输出。发布与账号操作仍按主技能的授权边界执行。

# 配图分工与背景连续性

用于多章节长图、改换品牌底色，或修复“配图重复、贴片感、接缝”的任务。先判断问题来自素材、构图还是合成；不要求每次重做全部图片。

## 给每张图一个作用

在排版或生成新图前，列一个简短的章节配图表：文字作用、视觉主体、构图方向、与相邻章节的连接方式。表格服务于当前内容，不固定段数或图片数量。

- 首图可以建立场景；后续章节可分别用细节、器物、人物活动或留白回应文字，不必再次展示同一完整场景。
- 共享画风、光感与少量装饰可以统一全篇；同一位图换裁切、镜像、缩放或重新着色，通常仍会被读者认作同一幅画面。
- 正文里的同一主体场景反复出现时，优先调整叙事分工、改用不同构图的素材，或让某章只保留文字与轻装饰。重新生成图片只是其中一种选择。
- 有意的首尾呼应、重复品牌标志、封面与首图共享主题可以保留；记录这种用途，避免机械地把所有重复都判为错误。

## 选择能融入版面的素材

独立花枝、灯笼、茶具等辅助插画适合使用真正的 alpha 透明背景，让页面底色直接显露。透明不等于应删去白色或压暗色像素：对象上的高光、花瓣和浅色釉面都应保留。

完整山水或室内场景可以是不透明图片，但需要有意安排场景边界。四边同色的生成要求有助于合成，仍不能保证最终融合。纹理密度、亮度梯度与色温都可能暴露图片的矩形范围。

需要生成或编辑图片时，在提示中说明：

- 当前章节的独特主体与构图，以及要避开的其他章节主体；
- 文字留白的位置，禁止绘制精确文字与 Logo；
- 透明辅助插画或完整场景的预期用途；若提供底色，描述接缝处的光感和纹理需求，而不只写一个十六进制色值。

## 在最终背景上处理边缘

1. 先按最终显示尺寸、坐标与底色放入素材；孤立看原图容易漏掉贴片感。
2. 查看所有可见边和角，以及任何延伸到页面边缘的位置。检查色差、纹理骤停、光晕、直线色带和四角底片。
3. 若边缘仍在主体之外，可在空白背景或自然雾气中做柔和过渡。遮罩不能穿过杯沿、花瓣、山脊等需要完整呈现的边缘，也不能影响正文或 Logo。
4. 若没有足够安全的过渡区域，应移动或缩放素材、换用透明辅助图、调整构图或修改素材；不要靠大范围渐隐把主体洗掉。
5. 将上下章节连起来检查。单张切片看起来自然，不代表拼接后没有突变；同时注意连续重复的大面积留白。

只修改 CSS 底色或给图片整体降低透明度，经常会产生灰蒙的主体与更明显的底片。先解决素材边界和空间关系，再微调色彩。

## 以读者看到的组合复核

用以下视图互相补充，而不是只看文字对比度报告：

- **整篇缩览：**检查视觉节奏、主体变化、章节之间是否像重复模板。
- **配图缩略图对照：**将正文配图并排，识别同一场景的不同裁切；封面和有意呼应单独标明用途。
- **章节交界与边缘近看：**检查矩形底片、截断物体、光晕及渐变色带。
- **手机宽度实际阅读：**检查正文、Logo 与配图主体在缩放后是否清楚，图是否挤占了阅读空间。

可见的非刻意重复、矩形底片或被遮罩截断的主体，应作为当前设计未完成的问题处理。自动化可以统计资产复用和生成对照图，但近似画面与融合质量仍需视觉判断；不要把“没有相同文件”或“文字对比通过”写成融合通过。
